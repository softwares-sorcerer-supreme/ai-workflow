What this is

ai-runner is a .NET 10 worker that runs on a developer laptop. It watches issues and pull requests on a GitBucket server, runs GitHub Copilot CLI to analyse, break down, implement and review them, and writes the results back as comments, labels, branches and PRs. A human always merges.

These pages were written by reading the code. Every claim points to a file and line. Where something could not be confirmed, it is listed under Open questions. The diagrams are Mermaid. Click a diagram to open it full screen.

Five things to know first

1. Jobs plan againEvery job re-reads GitBucket and asks JobPlanner again. Planner rules are the single source of "should this run".
2. GitBucket is the databaseState is in labels and hidden comment markers. Deleting ai-runner.db is safe.
3. Agent code runs on the laptopBuild and test commands run what the agent wrote, with your rights. It is a guard rail, not a sandbox.
4. Keep output ASCIIThis GitBucket returns HTTP 500 on non-ASCII text. Templates stay ASCII and all outgoing text is cleaned.
5. Template, parser, agent and sample change togetherChanging a template means changing its parser, the agent file and tests/AiRunner.Tests/Samples.cs.
